About & privacy

Chillspace makes simple, clean printables for kids. Puzzles are generated from checked word lists, so every word is spelled correctly and every answer key matches its puzzle.

You may print the files for personal, home-school and classroom use. Please link to this site instead of re-uploading the PDFs.

Privacy

This site has no accounts, no forms and no ad trackers. The name tracing maker runs entirely in your browser; the name you type is never sent anywhere. The site is hosted on GitHub Pages, which may keep standard server logs.
